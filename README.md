# Rating System

This is a simple React project that uses components, props, and hooks to create a star rating system.

Users can click on stars to give ratings and open a dialog box message.

---

## Features

- 5 clickable stars
- Dynamic rating messages
- Dialog box component
- React props
- useState hook
- Functional components
- React Icons

---

## Technologies Used

- React
- JavaScript
- CSS
- React Icons
